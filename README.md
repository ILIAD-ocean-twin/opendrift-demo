# ILIAD OpenDrift Demo

## Purpose

This repository contains a demonstration of how to use OpenDrift / OpenOil to model dispersal of an oilspill from platforms on the Norwegian continental shelf.

The notebook are located in `./notebooks`.

## Prerequisites

```sh
$ uv sync
```

## Usage

```sh
$ uv run jupyter lab
```
